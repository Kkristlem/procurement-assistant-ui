# Procurement Assistant UI — тестовое задание

React + Redux Toolkit поверх мок-API планирования закупок. Реализовал функционально полно:
каталог, план закупок с бюджетами, чат. Тестами не покрывал — на тестовое задание отвёл один
вечер и решил, что для оценки важнее полнота функциональности, а не тестовая инфраструктура,
которую в реальном проекте настраивал бы вместе с командой под её конвенции.

## Запуск

```
npm install
npm start
```
